# שרון מזגנים — Sharon AC Service

Static marketing site for an air-conditioning technician in Netanya, built with Vite + React and deployed to Cloudflare.
Three languages are served as prerendered static pages:

| Language | URL   | Direction |
| -------- | ----- | --------- |
| עברית    | `/`   | RTL       |
| English  | `/en/` | LTR      |
| Français | `/fr/` | LTR      |

## Develop

```bash
pnpm install
pnpm dev        # http://localhost:3000
pnpm check      # typecheck
pnpm build      # client build + SSR prerender → dist/
pnpm preview    # serve dist/
```

`pnpm build` produces `dist/index.html`, `dist/en/index.html`, `dist/fr/index.html`, `dist/404.html`,
`sitemap.xml` and `robots.txt`. Every page ships with full server-rendered HTML, per-language
`<title>`/description/canonical, `hreflang` alternates, Open Graph/Twitter tags and JSON-LD
(`HVACBusiness`, `FAQPage`, `WebSite`).

## Deploy to Cloudflare

The site is deployed as a Cloudflare Worker with static assets (see `wrangler.jsonc`).

### One-time setup

1. In the Cloudflare dashboard create an API token with the **Edit Cloudflare Workers** template.
2. In this GitHub repository add:
   - Secret `CLOUDFLARE_API_TOKEN`
   - Secret `CLOUDFLARE_ACCOUNT_ID`
   - Variable `SITE_URL` — the public URL of the site, e.g. `https://www.sharonmazganim.com` (scheme optional) (used for canonical, hreflang, sitemap and OG URLs). Defaults to `https://sharon-mazganim.pages.dev` when unset.
3. Push to `main` — `.github/workflows/deploy.yml` typechecks, builds and runs `wrangler deploy`.

### Deploy from your machine

```bash
npx wrangler login
SITE_URL=https://your-domain.example pnpm deploy
```

### Custom domain

Workers → `sharon-mazganim` → Settings → Domains & Routes → add your domain. Then set `SITE_URL` to match and redeploy.

## Editing content

- Copy for each language lives in `client/src/i18n/{he,en,fr}.ts`.
- Business details (phone, WhatsApp number, service areas, opening hours used in structured data) live in `client/src/i18n/index.ts` (`BUSINESS`).
- Images are in `client/public/images/`. `hero-technician.svg` and `about-detail.svg` are placeholder illustrations — replace them with real photos (WebP, ~760×500 and ~560×500) and keep the same file names or update `Home.tsx`.
- The Open Graph image and icons are generated by `node scripts/og-image.mjs` (needs Playwright).
- The contact form has no backend: on submit it opens WhatsApp with the entered details prefilled.
- Analytics: add a tag script in the marked spot at the bottom of `client/index.html`.
